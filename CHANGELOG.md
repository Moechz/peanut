# Changelog

All notable user-visible changes to the PeaNUT TOS application package.

## 6.0.0-1 — 2026-11-11

### Added
- First release. PeaNUT (`brandawg93/peanut:6.0.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8082 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/peanutdocker/`.
